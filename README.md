# Routing Protocols Lab – Cisco Packet Tracer

## Project Overview

A hands-on Cisco networking lab created using Cisco Packet Tracer to practice and compare different dynamic routing protocols.

In this project, I configured the network using:

* RIPv1
* RIPv2
* EIGRP
* OSPF

The same network topology was used to understand how different routing protocols operate and how routing information is exchanged between routers.

## Routing Protocols

### 1. RIPv1

* Configured RIPv1 on the routers.
* Practiced classful routing.
* Verified routing tables and network connectivity.

### 2. RIPv2

* Migrated the network from RIPv1 to RIPv2.
* Practiced classless routing and subnet mask advertisement.
* Verified routes using Cisco IOS commands.

### 3. EIGRP

* Reconfigured the network using EIGRP.
* Configured the required networks and autonomous system.
* Verified EIGRP neighbors and learned routes.

### 4. OSPF

* Reconfigured the network using OSPF.
* Configured OSPF area 0.
* Verified OSPF neighbor relationships and routing tables.
